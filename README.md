# Awesome Chess Resources

A curated collection of open-source tools, databases, and resources for chess analysis and opening theory.

## Engines

- [Stockfish](https://github.com/official-stockfish/Stockfish) Strongest open-source engine, NNUE architecture
- [Lc0](https://github.com/LeelaChessZero/lc0) Neural network engine trained via self-play
- [Komodo Dragon](https://komodochess.com/) Commercial engine with free older versions available
- [Berserk](https://github.com/jhonnold/berserk) — Fast NNUE engine, consistent top performer in TCEC
- [RubiChess](https://github.com/Matthies/RubiChess) — Open-source NNUE engine with strong tactical play
- [Demolito](https://github.com/lucasart/Demolito) — Lightweight engine focused on clean code and correctness
- [Arasan](https://github.com/jdart1/arasan-chess) — Long-running open-source project, active since 1994
- [Igel](https://github.com/vshcherbyna/igel) — NNUE engine with competitive CCRL ratings

## Databases & APIs

- [Lichess Open Database](https://database.lichess.org/) Complete game archive, monthly PGN dumps
- [Lichess Opening Explorer](https://lichess.org/api#tag/Opening-Explorer) Query opening statistics via API
- [FICS Games Database](https://www.ficsgames.org/) Free Internet Chess Server game archive
- [365chess](https://www.365chess.com/) Opening reference with high-depth engine evaluations

## Analysis Tools

- [python-chess](https://github.com/niklasf/python-chess) Python library for chess move generation, validation, and engine communication
- [pgn-extract](https://www.cs.kent.ac.uk/people/staff/djb/pgn-extract/) CLI tool for filtering and converting PGN files
- [CuteChess](https://github.com/cutechess/cutechess) GUI for engine-vs-engine matches and tournaments

## Opening References

- [ECO Classification (Wikipedia)](https://en.wikipedia.org/wiki/Encyclopaedia_of_Chess_Openings) Standard opening taxonomy
- [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) Lichess opening name database
- [Wikibooks Chess Opening Theory](https://en.wikibooks.org/wiki/Chess_Opening_Theory) Community-maintained opening tree

## Learning

- [Lichess Studies](https://lichess.org/study) Create and share interactive analysis
- [Chess Stack Exchange](https://chess.stackexchange.com/) Q&A for serious chess questions
